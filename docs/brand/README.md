# GitStation のロゴとアイコン（v1）

UI（M2 以降の `web/`、ドキュメントポータル、`gstn` の出力など）で GitStation のロゴ・アイコンを出すときは、**必ずこのフォルダのファイルを使う**（ユーザーの指示 2026-10-30）。手で描き直したり、色や形を変えたりしない。

| ファイル | 内容 | 使う場所 |
|---|---|---|
| `gitstation-v1-icon.svg` | アイコンだけ（角丸の正方形、背景ネイビー、512×512） | favicon、アプリのアイコン、狭いヘッダー、アバター |
| `gitstation-v1-logo-dark.svg` | アイコン + 文字「GitStation」、背景ネイビー（暗いテーマ用） | 暗いテーマのヘッダー、ログイン画面 |
| `gitstation-v1-logo-light.svg` | アイコン + 文字「GitStation」、背景白（明るいテーマ用） | 明るいテーマのヘッダー、文書、印刷 |

## 色（ロゴに使われている値）

| 名前 | 値 | 用途 |
|---|---|---|
| ネイビー | `#1B2A44` | 暗い背景、明るいロゴの文字の後半 |
| ティール | `#22B8A0` | 主な線、暗いロゴの文字「Git」 |
| 濃いティール | `#128F7C` | 明るいロゴの文字「Git」 |
| オレンジ | `#FF7A45` | もう 1 本の線（強調） |
| 白に近い色 | `#F4FBFC` | 駅の中心、暗いロゴの文字の後半 |

UI のデザイントークンを作るときは、この値を起点にする（ロゴの色と UI の色をずらさない）。

## 注意

- テーマに合わせて dark / light を切り替える（`prefers-color-scheme` など）。暗い背景に light 版を置かない。
- ロゴは背景の矩形を含むので、別の背景色の上に置くと四角が見える。透明な背景が必要になったら、新しい版（v2）としてファイルを足し、この表を更新する。
- 新しい版を作るときは、ファイル名の `v1` を上げて残し、古い版は消さない。
