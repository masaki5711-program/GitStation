**Step 0（MR9 の積み残し、`cab60d0`）**: `ErrorNotice` の見出し id を `useId`、`Modal` は保存中に `close` が来たら（Chromium の 2 回目の Esc）開き直して親へ伝えない、`.input` は `.interactive` から外して（フォーカスの輪と hover の枠線だけ）、ヘッダーの言語の選択の `:active` を `--gs-header-active`、Layout の「遅れて出る h1」へのフォーカスはフォーカスが body / main にあるときだけ、保存中の主ボタンは `disabled` でなく `aria-disabled`（フォーカスを失わない。2 回押しても送らない）。テスト 3 つ（`tests/mr9-leftovers.test.tsx`）。

**画面（`web/src/pages/repo/`）**: 住所は `/{project}/-/{tree|blob|blame|commits}/{ref}[/{path}]`、`/-/commit/{oid}`、`/-/compare/{from}...{to}`、`/-/branches`、`/-/tags`。ref とパスの境目は `resolve` API に尾を丸ごと渡して決める（ref に `/` があってもよい）。以降の API には解決した完全な ref 名（タグ・ブランチ）かコミット ID を渡す。

- **木**（`TreeScreen`・`TreeListing`）: フォルダが先、サブモジュールはリンクなし、シンボリックリンクの印、親へ戻る行、パスのパンくず、ブランチ・タグの切り替え（`<select>`）、zip / tar.gz のダウンロード（`/-/archive/{ref}.{zip|tar.gz}`、サーバーの経路への素のリンク）、clone の URL（コピー）、README（`.md` は Markdown、`.txt` は文字）。5 000 件で切れたら「先頭の N 件だけ」。ref のない `/-/tree` は既定のブランチ、ブランチのないリポジトリは「空」。プロジェクトのトップにも同じ一覧と README と画面へのリンク。
- **ファイル**（`BlobScreen`）: 行番号つき（CSS のカウンター。コピーに混ざらない）、`#L12` の行の id、生のファイル・ダウンロード・blame・履歴のリンク。1 MiB で切れたら全体のサイズと一緒に言う。バイナリは表示せずダウンロード、png / jpeg / gif / webp は raw から `<img>`、SVG・HTML・XML・PDF は「描かない」の注意（テキストのものは中身を `<pre>` の文字として見せる。§5 の確認事項）。シンボリックリンクは行き先、空のファイルは「空」。Markdown は「整形して表示 / 元の文字」の切り替え（`aria-pressed`）。
- **blame**（`BlameScreen`）: ハンクごとにコミット（短い ID のリンク、件名、作者、日付）、行番号、色つきのコード。10 000 行・バイナリはそれぞれ文で言う。
- **コミット一覧**（`CommitsScreen`）: キーセットのカーソル（`useInfiniteQuery`。「さらに読み込む」が `cursor` を付けて次を読む）、次のページが失敗しても前のページを残して再試行、パスの履歴（`/-/commits/{ref}/{path}`）、マージの印。
- **コミット**（`CommitScreen`）: 全文のメッセージ、作者・記録者、ID（コピー）、親のリンク、差分。**差分**（`DiffView`）: 追加・削除は色と `+` / `-` と読み上げ用の文字、行番号 2 列、ファイルごとの状態（追加・削除・名前の変更と類似度・コピー・種類の変更）、`binary`・`too_large`・`total_cap`・`not_utf8`・名前だけ・モードだけ・未知の `omitted` を文で言う、600 行を超えるパッチは畳んで「差分を表示（N 行）」、差分全体の `truncated` の注意。
- **比較**（`CompareScreen`）: 2 つの入力（ref の候補つき）→ `from...to`、`to` にだけあるコミット（200 件で切れたら言う）と差分。存在しない ref はサーバーの文言 + request_id。
- **ブランチ・タグ**（`RefsScreen`）: 既定の印、コミットへのリンク、各 ref の archive、コミットでないタグは「コミットではないもの」（リンクなし）、5 000 件の切り詰めの注意。
- **エラー**: 解決できない ref・パス（FG-REPO-0023、404）は「見つかりません」の見出し + サーバーの `user_message` + `request_id`（汎用の 404 ではない。プロジェクトは見えているので存在の手がかりにならない）。それ以外は `QueryError`（401 でログイン、403、再試行）。

**Markdown（`features/Markdown.tsx`、別チャンク）**: `react-markdown` 10.1.0（MIT）+ `remark-gfm` 4.0.1（MIT）。**生の HTML は `skipHtml` で捨てる**（`rehype-raw` なし。HTML の文字列を作らない）。`urlTransform` は http / https / mailto / `#` / 相対だけを通し、制御文字・バックスラッシュ・`//…`・それ以外のスキームを捨てる。外部のリンクは `rel="noopener noreferrer"`。画像は同じリポジトリの png / jpeg / gif / webp を `/-/raw/{ref}/{path}` にしたものだけ（外部・`data:`・SVG・HTML・PDF・ルートより上は描かず、外部はリンク）。相対リンクは同じ ref の画面へ（`..` で外に出るものはリンクにしない）。見出しの id は `user-content-` + 文字列、`#x` のリンクも写す。表・コードは名前つきの `role="region"` + `tabindex=0`。見出しの段は `headingOffset`（README +2、ファイル +1）。

**構文の色（`features/highlight.ts`）**: `lowlight` 3.3.0（MIT）+ `highlight.js` 11.11.1（BSD-3-Clause）。木のまま React の要素にする（`innerHTML` なし）。通すのは `hljs-*` のクラスだけ、`style` 属性なし。言語 23 個は別チャンク、20 万文字超は色なし。色は `tokens.css` の `--gs-code-*`（コードの背景の上で 4.5:1 以上。`tokens.test.ts` の対に足した）。

## 5. 確かめていないこと・利用者に決めてほしいこと

- **実サーバーでの通し**（実 `forge serve` + 本物のリポジトリ）。journey はスタンドイン。raw・archive のリンクは素のリンクで、サーバーの実装（MR7）に頼る（HEAD / GET の挙動は Rust のテストで確認済み）。
- **決めてほしい**: SVG・HTML・XML のテキストを、画面で文字として見せてよいか（いまは見せる）。ダウンロードだけにするなら `BlobScreen.tsx` の `!file.binary && … text !== null` の条件に `!isDownloadOnly(path)` を足す 1 行。
- 巨大なファイル（1 MiB・数万行）は全行を DOM に出す（20 000 行の表示のテストはあるが、実機の描画時間は測っていない）。必要なら仮想化（別の MR）。
- 差分の構文の色付けはしていない（コードの表示と blame だけ）。
- ref の切り替えは `<select>`（5 000 件までの全部を並べる）。多いリポジトリは検索つきの選択が欲しくなる（Radix の許可リストに足す MR）。
- ブラウザは Chromium だけで確認（Firefox・Safari は未確認）。
- Rust 側は変更なし（fmt / clippy / cargo は走らせていない）。レビューエージェントは未実行。
