## 3. MR4 の中身（ADR-0008 の MR4 の追記が正）

- ルート: `GET|HEAD {path}.git/info/refs?service=git-receive-pack`、`POST {path}.git/git-receive-pack`（`app::PLANNED` から
  `RepoPush` を外した）。プロジェクトの `RepoPush` は本文を読む前に判定する。`moved` の墓石を通る push は 404 のまま。
- コマンド部の厳密な解析（`forge_git::receive_request`）: 1000 件・1 MiB、`report-status` 必須、`push-cert` 拒否、capability は
  最初の行だけで既知のものだけ、ref は `RefName::parse`（FG-GIT-0005）と 16 進の名前（FG-GIT-0011）。git の「確かめ」の要求
  （`0000` だけ）は git を起動せずに 200。
- 判定: 規則を 1 回読み、各更新を分類（作成 / 削除 / 既存タグの更新 = force / 保護ブランチで新しいコミットが既にあれば
  `Git::fast_forwards`）し、`forge_auth::authorize_ref_updates`（新しい API。プロジェクトの証明を受け取り、ref ごとに
  `authorize()`）で判定。1 つでも拒否なら本文を読み捨て（64 MiB まで）、git を起動せず、帯域内で全体を拒否
  （`ng <ref> <FG コード> <文言>`、他は `atomic push failure`、サイドバンド 2 に request_id 付き）。
- 許可: receive-pack に元のバイト列をそのまま渡す。保護ブランチを更新するなら `-c receive.denyNonFastForwards=true`、
  git の `non-fast-forward` は保護 ref について FG-GIT-0007 に書き換える（`forge_git::receive_report::ReportRewriter`）。
  上限: パック `git.http.push_max_bytes`（新しい設定、既定 2 GiB）、本文はその + 1 MiB、1 時間、無通信 60 秒。
- 本文を受け取り終えたら receive-pack はリクエストの持たないタスクで動く。終了後、`ok` の ref の種類とコミット（20 件まで、
  10 秒、超えたら `total_commits_partial` — forge-core の `PushedRef` / `PushAppliedRef` に足した欄）を読み、
  `forge.git.push_applied` を先にログ、それから `record_push` を 30 秒以内に 3 回、だめなら FG-GIT-0012。
- 認証したトークンの ID を要求の拡張に残す（`Dispatched::credential_id`、記録の `credential_id`）。
- 権限表: `RepoPush` × プロジェクトの行を 9 つ追加（Anonymous / Disabled / Guest(internal) / Maintainer / Owner / Admin /
  DevTokenApi / DeletedProject / KindMismatch）。`docs/authz`、OpenAPI、`docs/errors` を再生成。

## 4. 確かめたこと（このセッションで実行）

ゲートの結果はコミットの報告にある（§6）。実際の git の e2e（`smart_http_e2e.rs`、28 件、うち push 12 件）:
read / api トークンの拒否、ブランチとタグの作成と記録（監査 1 行・イベント 1 件、コミット付き）、保護ブランチへの
Developer の push = 0008、管理者でも force = 0007（forge の事前判定と git の拒否の書き換えの両方）、保護ブランチの削除 = 0009、
`refs/replace/x` = 0010、16 進の名前 = 0011、混ざった push は全体を拒否、保護タグの付け替え = 0007、墓石への push = 404、
上限超えの push（`postBuffer` を超えるので git の「確かめ」も通る）、fsck の拒否、DB が落ちたときの FG-GIT-0012
（`forge.git.push_applied` が先で、一覧付き）。記録の再試行は `routes/git_push_tests.rs`（時間を止めたテスト）。
