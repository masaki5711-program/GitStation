## 3. ADR・計画との違い（決めたこと、ADR-0021 の 29〜31）

1. **ID トークンのないリフレッシュは 3 回続けてまで**（ADR §7 は「絶対の寿命まで保つ」）。4 回目で `idp_revoked`。
2. **セッションのないログアウトは 303 ではなく FG-AUTH-0001**（権限の表で匿名は deny）。画面はセッションがあるときだけボタンを出す
   （MR9 への申し送り）。`auth.oidc` のないサーバーでは 503 FG-AUTH-0018 でセッションは残す。
3. `SessionContinue` の `decided_in` は `/api/v1/session`（実際は Cookie で認証するすべてのルート）。
4. 計画 10 の `POST /api/v1/session/logout` は ADR §8 のとおり `POST /-/auth/logout`。

計画の文書（`docs/plan/`）は変えていない。
