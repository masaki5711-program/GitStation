## 2. 入れたもの

- **ログイン**（`pages/Login.tsx`、`features/SignInPanel.tsx`、`features/signin.ts`）: セッションがなければ、**同じ URL のまま**ログイン画面（1 ボタン「IoT ポータルでログイン」）。`next` はいまのページ（`safeNext` が `/…` 以外・`//`・`\`・制御文字をホームにする。サーバーも同じ規則）。ボタンは `GET /-/auth/login?next=` を `redirect: 'manual'` で先に確かめ、`opaqueredirect` なら `location.assign`。**503 + FG-AUTH-0018** は「ログインがまだ設定されていません」の 1 行 + `request_id`（コードは出さない）。ほかの失敗は `ErrorNotice`。使っている途中で 401 になったときは、そのページの `QueryError` がログインを出し、戻り先はそのページ。
- **セッションと CSRF**（`session/session.tsx`、`api/client.ts`）: `GET /api/v1/session`（401 = 未ログイン）。`csrf_token` はメモリにだけ置き（`api.csrf`）、状態を変える要求（GET / HEAD / OPTIONS 以外）に `X-GitStation-CSRF` を付ける。
- **ヘッダー**（`components/Header.tsx`、`UserMenu.tsx`）: ロゴ、言語の選択（ブラウザの中だけに覚える。変えると API を引き直して `user_message` も新しい言語になる）、利用者のメニュー。**ログアウトは `<form method="post" action="/-/auth/logout">` + `csrf` の隠しフィールド**（MR5 の引き継ぎどおり。ブラウザ自身が 303 を追う）。ポータルのアプリ切り替えは出していない（§4）。
- **ホーム**（`pages/Home.tsx`）: 自分のプロジェクト（`membership=true`、名前・パスの絞り込み）、仕様書（`kind=spec`）、自分のグループ、最近見たもの（`localStorage`、読めなくても空になるだけ）。読み込み中・空・失敗（再試行）の状態あり。中身のない枠は出さない（仕様書・グループ・最近は、あるときだけ）。
- **一覧の読み方**（`api/pages.ts`）: カーソルのページを最後まで（最大 10 ページ = 1000 件）読み、上限で切れたら「一部しか表示していません」と出す。**空のページが途中に来ても `has_more` で続ける**（API の走査の上限の仕様）。
- **グループ・個人の名前空間**（`pages/GroupPage.tsx`）: 直下のサブグループとプロジェクト。**一覧 API に親の絞り込みがないので、見える一覧を読んでパスの親で絞る**（§4）。作成ボタンはロールがあるか管理者のときだけ。
- **プロジェクトのトップ**（`pages/ProjectPage.tsx`）: 概要、clone の URL（`{origin}/{path}.git`、コピー）、リポジトリの状態（`repository/refs`: 空なら最初の push の手順、あれば既定のブランチとブランチ・タグの数）。ファイルの閲覧は MR10。
- **作成**（`features/CreateDialogs.tsx`、`ui/Modal.tsx`）: HTML の `<dialog>`（`showModal()`）の中のフォーム。プロジェクト（置き場所 = 自分の名前空間 or メンバーのグループ、名前、パス、説明、公開範囲、種類）、グループ、サブグループ。パスは名前から提案し（ASCII だけ）、ADR-0015 の正規表現で先に確かめ、あとはサーバーの `user_message` + `request_id`（入力は残す）。成功したら新しいページへ。
- **URL の救済**（`pages/Namespace.tsx`、`Permalink.tsx`）: `resolve?prefix=true`。GitHub 形（`/acme/web/tree/main/src`）は `/acme/web/-/tree/main/src` へ `replace`（画面の語の許可リストにない `pull/3` などは 404）。移動したパス・綴りの違いは正規のパスへ `replace` し、移動なら遷移先に「この場所は移動しました。以前のパス：…」。`/-/projects/{id}[/…]` は現在のパスへ。デコードできないパス・正でない id は問い合わせずに 404。404 以外の失敗は 404 にせず `ErrorNotice`。
- **404・エラー**: `NotFound`（見えないものも同じ文言: ADR-0015）、`ErrorBoundary`（描画の例外は 1 回ログに出して一般のエラー）、`/-/…` で画面のないものは 404。
- **API の型**: `docs/api/openapi.json` に対して `schema.gen.ts` が古かった（MR1 の時点のまま。session・groups・resolve のクエリが無かった）ので `npm run gen:api` で作り直した。
- **トークン**: 主ボタンの白文字を `--gs-brand-teal-strong`（4.0:1）から新しい `--gs-color-action`（`#0f7a69`、5.4:1）に。axe の color-contrast（実ブラウザ）が見つけた。`tokens.json` とコントラストの検査に 1 組足した。
- **辞書**: ja / en / id の 102 キーすべて（id の欠け 0）。直書きの文字列なし（lint が止める）。
