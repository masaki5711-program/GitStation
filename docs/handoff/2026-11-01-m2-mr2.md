## 3. 計画・ADR との違い（ADR-0022 の Amendment「M2 MR2」に記録）

1. `teal-strong` は白地で約 4.0:1 で本文の AA に足りない → リンクは新しいトークン `--gs-color-link`（`#0F7A69`）。
2. ヘッダーはネイビーなので dark 版のロゴ（ブランドの README の規則）。
3. ブランドの資産は写しをコミットし、SHA-256 をテストで比べる（ビルドの時に写さない）。
4. `form-action` の IdP のオリジンと HSTS は `SecurityHeaders::new` が受け取るが、設定のキー（`web.hsts`、`auth.oidc`）は MR3 / MR4 でつなぐ
   （MR3 が `web.*` の名前空間を作るので、衝突を避けた）。
5. Radix は入れていない。部品の見本の画面と Playwright の巡回は、最初の Radix の部品を足す MR で。
6. Playwright は `forge serve`（DB が要る）ではなく、dist を forge-web と同じ形で返す Node の代役に当てた（CSP は Rust の定数を読む）。
   `npm run smoke -- --url <forge serve>` で本物にも当てられる。
7. MSW は使っていない（openapi-fetch に `fetch` を渡してテストする）。
8. vitest 4.1.12（3 系は tinypool の critical）。npm 10.9.4 が vitest 4 の peer の解決で落ちるので lockfile は npm 11.6.2 で作った。
   `npm ci --ignore-scripts` は npm 10.9.4 で通ることを確かめた。残る勧告は開発の依存の minimatch（moderate × 14）。本番の依存は 0。

## 6. レビュー（a8270bd）の指摘と対応（2 つ目のコミット）

Opus（Rust・CI）と Sonnet（web）の評価: どちらも WARN、HIGH なし。全部に対応した。

| # | 重さ | 対応 |
|---|---|---|
| 1 | MEDIUM | Chromium の検査を別のジョブ `web-smoke`（`web-dist` を受け取る）に分けた。playwright 1.63.0 を lockfile の devDependency にした（ブラウザは `npx --no-install playwright install` で取る）。dist を作る `web` のジョブは `npm ci --ignore-scripts` の外で何も入れない |
| 2 | LOW | web・web-smoke・release のジョブの action をコミットの SHA に固定（コメントにタグ）。`dtolnay/rust-toolchain@master` も SHA に |
| 3 | LOW | `security_headers` の「その他」（資産の 404、health、リダイレクト）に `Cache-Control: no-store`（ルートが付けたものは残す） |
| 4 | LOW | `Accept-Encoding` の `q` は RFC 9110 の qvalue の文法だけ（0〜1、小数 3 桁まで）。`inf`・`NaN` などは受け付けない扱い。テスト `only_the_qvalue_grammar_is_a_q` |
| 5 | MEDIUM | `alt`・`title`・`placeholder`・`label`・`aria-label` などの直書きを `no-restricted-syntax` で止める（`ignoreProps: false` はこの版では `id`・`role`・`href` まで止めるので採らない）。`tests/lint-rules.test.ts` が規則が効くことを確かめる |
| 6 | MEDIUM | `call()`: abort はそのまま投げ直す、`TypeError` は `network`（`cause` を保つ）、ほかは `unexpected`（`status: null`）で `console.error` に 1 回。2xx で本文がないのも `unexpected` |
| 7 | MEDIUM | Home: `ApiFailure` でない失敗は `failureOf()` で `unexpected` にし、1 回ログ |
| 8 | LOW | 禁止の import に `@stitches/*`・`goober`・`@mui/*`・`@chakra-ui/*`・`@mantine/*`・`antd` などを足した（`src/ui/` でも禁止）。`index.html` のインラインの `<script>`・`<style>`・`style=`・`on*=`・`javascript:` を build（`compress.mjs`）と smoke で拒否（`scripts/inline-check.mjs`、テストつき） |
