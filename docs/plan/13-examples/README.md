## 確かめた形式の要素

| 要素 | どこで |
|---|---|
| frontmatter の必須 4 項目と型の追加の項目（和文の値・リスト） | 3 つとも |
| 表（和文・記号・表の中の `[[ ]]`） | QP の責任と権限、RA の尺度と残留リスク |
| ブロック（属性なし・語の値・引用符の値・`status=deprecated`） | QP の `step`、RA の `hazard`・`control`、URS の `req`・`decision`・`check` |
| ID の無い入れ物の入れ子（ID のあるブロックの中の `::: note`） | QP の S-2 |
| 参照: 文書・ブロック・同じ文書のブロック・他の文書のブロック | QP→QM-001、RA→URS-L3-001#REQ-L3-012、URS→RA-2026-014#C-01a |
| 1 文 1 行で分けない場所: `「…。」`・`（…。）`・表・コードのフェンス | RA の H-03、URS の REQ-L3-011、Mermaid |
| HTML のコメント（合成の印） | 3 つとも |

## 期待する lint の結果（段 2 の試験の期待値）

この 3 つと型の定義だけのリポジトリとして検査したときの、**わざと残した**エラー:

| 文書 | 規則 | 箇所 | 理由 |
