## 対象と範囲

対象は、第 3 ラインのプレス機 No.3（[[URS-L3-001]]）の通常の生産・金型の交換・詰まりの除去の作業である。
見積りの尺度は、重大さ（1〜4）と起こりやすさ（1〜4）の 2 つで、リスクの値はその積とする。

| 値 | 重大さ | 起こりやすさ |
|---|---|---|
| 1 | 軽い（応急の手当て） | ほとんど起きない |
| 2 | 休業 4 日未満 | 年に 1 回程度 |
| 3 | 休業 4 日以上 | 月に 1 回程度 |
| 4 | 死亡・後遺障害 | 週に 1 回以上 |

## 危険源の特定とリスクの見積り

::: hazard H-01 severity=4 likelihood=2 res_severity=4 res_likelihood=1
スライドの下降中に、ガードの開口部から手が入る。
対象の作業: 金型の交換、詰まりの除去。
:::

::: hazard H-02 severity=2 likelihood=3 res_severity=2 res_likelihood=1
製品の取り出しのときに、端材のばりで指を切る。
:::

::: hazard H-03 severity=3 likelihood=1 res_severity=3 res_likelihood=1
油圧の配管の継手から作動油が漏れ、床で滑る（「漏れが無いことを始業の点検で確かめる。」と点検表にある）。
:::

## リスク低減措置

::: control C-01a for=H-01 type=engineering
ガードにインターロックを付け、開いたらスライドを止める（[[URS-L3-001#REQ-L3-012]]）。
:::

::: control C-01b for=H-01 type=administrative
金型の交換は、[[QP-07-001]] に基づく作業手順書で行い、ロックアウトを必須にする。
:::

::: control C-02 for=H-02 type=ppe
耐切創の手袋（レベル C 以上）を使う。
:::

::: control C-03 for=H-03 type=administrative
始業の点検で継手の漏れを確かめ、漏れがあれば運転しない。
:::
